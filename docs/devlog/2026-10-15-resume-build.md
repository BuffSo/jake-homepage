## 바로잡은 것

- **인쇄 페이지 나눔**
  - 처음에는 제목(h2, h3)만 다음 내용에 붙였습니다.
  - A4 PDF로 찍어 보니 하트링크의 제목, 직함 줄, 스택이 5장 끝에 남고 본문은 6장으로 넘어갔습니다.
  - 경력과 프로젝트의 머리 묶음과 "Peer Review" 줄까지 다음 내용에 붙여, 장이 항목 경계에서 끊기게 했습니다.
- **모바일 연락처 표**
  - 전역 `overflow-wrap: anywhere` 때문에 두 칸짜리 표가 좁아졌습니다. GitHub 주소가 "Buff / So"로 갈라졌습니다.
  - 이력서 표 칸만 `normal`로 바꿨습니다.
- **개발 서버의 예전 CSS**
  - 개발 서버가 `globals.css` 수정을 놓치고 예전 규칙을 내줬습니다. 그래서 고친 인쇄 규칙이 처음에는 PDF에 반영되지 않았습니다.
  - 내려받은 CSS에 새 규칙이 있는지 먼저 확인하고 서버를 다시 띄워 비교했습니다. 최종 확인은 프로덕션 빌드(E2E)로 했습니다.
