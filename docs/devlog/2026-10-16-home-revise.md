## 바로잡은 것

- **층 단위 강조**: F1에서 층마다 서비스를 묶었습니다. 같은 층 안에서도 기술마다 쓴 서비스가 달라, API 층을 누르면 TypeScript를 쓰는 GENYS Lotto AI가 흐려졌습니다. AI 층도 Claude Code를 쓰는 ProWith를 빠뜨렸습니다.
- **낱말 기준의 사실 확인**: 사실을 원문 낱말로만 대조하다 보니, 원문에서 분명히 따라 나오는 사실(Node.js, React)까지 빼자고 제안했습니다. 사람이 바로잡았습니다. 지금은 따라 나오는 관계도 데이터에 근거로 적고, 테스트가 그 근거 낱말이 원문에 있는지 확인합니다.
- **커밋 훅 오탐**: 같은 명령에 `grep -n`이나 `sed -n`과 `git commit`이 함께 있으면 Claude Code 훅이 `--no-verify`로 잘못 읽고 막습니다(todo 03). 명령을 나눠 진행했습니다.
