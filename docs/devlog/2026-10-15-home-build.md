## 바로잡은 것

- **공개 범위를 잘못 보고함**: Vercel의 첫 배포가 브랜치 커밋인데도 production으로 잡혀, vercel.app 프로덕션 주소에 브랜치 화면이 올라갔습니다. 이 주소도 로그인 보호를 받는다고 보고했지만, 로그인 없이 요청해 보니 열렸습니다. 공개 여부는 로그인 없는 요청으로 확인한 뒤 말합니다. 보이는 내용은 공개할 사이트 문구뿐이었습니다.
- **브랜치의 규칙 파일**: 브랜치가 "브랜치와 PR" 규칙을 넣기 전에 갈라져, 새로 시작한 세션이 브랜치의 예전 CLAUDE.md를 읽었습니다. main을 브랜치에 merge commit으로 합쳐 맞췄습니다.
- **서버 출력 크기**: 콘텐츠 파일을 변수 경로로 읽어서, Turbopack이 프로젝트 전체를 서버 출력에 넣는다고 경고했습니다. 읽는 경로를 `content/site` 아래로 고정했습니다.
- **고정폭 글꼴의 한글**: 스토리보드대로 한글 안내를 고정폭으로 쓰니 띄어쓰기 폭이 넓어 낱말 사이가 벌어졌습니다. 고정폭은 기술 이름, 주소, 번호에만 쓴다고 [03-design.md](../03-design.md#타이포그래피)에 적었습니다.
- **움직임 용량 오측정**: 재생 코드가 next/image의 클라이언트 코드와 한 청크에 묶여 9.2KB로 쟀습니다. 재생 코드를 나눠 재생할 때만 불러오게 하니 2.2KB가 됐고, 다시 방문한 사람은 이 코드를 받지 않게 됐습니다.
- **재생 시간 초과**: 데스크톱 재생이 3.04초로 기준(3초)을 넘었습니다. 끝을 알리는 데 프레임이 더 들기 때문이라 재생을 0.96배로 줄였습니다. 테스트는 여유를 두지 않고 기준 그대로 봅니다.
- **오래된 빌드**: 색 토큰을 바꾼 뒤 첫 빌드가 예전 CSS를 내보내 다크 모드 테스트가 실패했습니다. `.next`를 지우고 다시 빌드하자 통과했고, 그 뒤로는 다시 일어나지 않았습니다.
- **커밋 가드 훅 오탐**: 훅 건너뛰기를 막는 Claude Code 훅(`scripts/hooks/guard-git-commit.mjs`)이 명령 전체에서 `git`, `commit`, `-n`을 따로 찾습니다. 그래서 커밋과 같은 명령에 `grep -n`이 있거나, 이 훅 파일을 `sed -n`으로 읽기만 해도 막혔습니다. 이 일지를 고치는 명령도 문장 속 낱말 때문에 막혔습니다. 커밋 명령은 따로 실행하고 있고, 훅은 따로 고칩니다([docs/todo](../todo/20261015_03_todo_commit_guard_false_positive.md)).
