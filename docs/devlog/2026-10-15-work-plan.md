## 바로잡은 것

- **기간 부풀리기**: AI TOOLS의 기간을 저장소의 첫 커밋과 마지막 커밋으로 잡아 제안했습니다. 마지막 커밋은 석 달 뒤의 README 정리 하나였고, 구현 커밋 46개는 이틀 사이(23시간)에 있었습니다. F1 시안의 "커밋 46개 · 23시간"과 맞지 않는 것을 시안을 그리며 발견해 다시 확인받았습니다. 기간은 커밋 날짜 분포를 보고 구현 커밋이 몰린 기간으로 쓴다고 [02-ia.md](../02-ia.md#work-포트폴리오-f2)에 적었습니다.
- **이미지 속 개인정보**: 민감정보 검사는 글자만 읽어서 이미지 속 이름과 이메일을 잡지 못합니다. 포트폴리오 이미지는 열어서 확인했고 싣지 않았습니다.
- **고정폭 한글**: 시안은 역할과 기간 줄을 고정폭으로 그렸습니다. 한글 문장은 고정폭으로 쓰지 않는다는 원칙에 따라 구현에서는 본문 글꼴로 쓴다고 [03-design.md](../03-design.md#f2에서-정한-값)에 적었습니다.

## 검증

- 사이트 두 곳과 공개 저장소 두 곳을 열어 확인했습니다. Brain House의 일본어 전환은 라이브에서 눌러 확인했습니다.
- 사이트 캡처는 한국어 첫 화면(1280×800)이고, 이메일과 회사 정보가 있는 푸터는 들어오지 않습니다.
- 시안 아트보드는 템플릿 변수 없이 정적 마크업으로 써서, 같은 원본을 헤드리스 Chromium으로 그려 캡처했습니다. 데스크톱과 모바일 모두 가로 스크롤이 없고, PNG에 텍스트 메타데이터가 없습니다.
- 마크다운 변환기 후보의 패키지 수는 빈 폴더에 각각 설치해 셌습니다.
