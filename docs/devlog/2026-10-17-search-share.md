## 한 일

- 네 페이지에 대표 주소(canonical)와 공유 정보(Open Graph, X 카드)를 두었습니다. 메신저나 메일로 링크를 보내면 제목, 설명, 그림이 보입니다.

- robots.txt(모두 허용)와 네 페이지 사이트맵을 두었습니다.
- 홈에 한 사람의 페이지임을 알리는 구조화 데이터(ProfilePage, Person)를 두었습니다.
- 정한 정책을 [검색과 공유 정책](../guide/SEO_검색과_공유_정책_20261017.md) 가이드로 남겼습니다. 이 저장소의 첫 가이드입니다.

## 바로잡은 것

- **그림이 홈에만 붙은 것**: 처음에는 그림을 Next의 파일 규칙(`app/opengraph-image.png`)으로 두었습니다. 빌드 결과를 페이지마다 열어 보니 하위 페이지 세 곳에는 그림 태그가 없었습니다. 하위 페이지가 정한 `openGraph`가 부모의 `openGraph`를 통째로 바꾸면서 그림도 덮였기 때문입니다. 그림을 가져온 파일로 바꿔 도우미가 페이지마다 넣게 했고, E2E가 네 페이지 모두에서 그림 태그와 크기를 봅니다.
