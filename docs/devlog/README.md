# 작업 일지 (devlog)

기능(PRD의 F 번호) 하나가 끝났을 때, 또는 그 사이에 AI 제안과 제 판단이 갈린 일이 있었을 때 한 건씩 남깁니다. 파일 이름은 `YYYY-MM-DD-주제.md`입니다.

이 일지는 AI가 무엇을 제안했고 제가 무엇을 판단했는지 구분해서 적는 곳입니다. 대화 원문은 붙이지 않고 요약합니다. 무엇을 바꿨는지는 커밋에, 되돌리기 어려운 결정은 ADR에 있으므로 여기서 되풀이하지 않습니다.

## 양식

```md
# YYYY-MM-DD 주제

## 한 일
## 흐름
| # | AI 제안 | 판단 | 결과 |
## 바로잡은 것
에이전트가 잘못한 것과, 그것을 막으려고 규칙이나 장치에 추가한 것
## 검증
돌린 명령과 결과를 짧게. 자세한 결과는 CI 실행 링크로 대신합니다
## 다음
```
