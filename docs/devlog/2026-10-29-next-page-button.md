# 2026-10-29 다음 페이지 버튼

## 한 일

- 사이트를 헤더 순서(홈, `/work`, `/ai`, `/resume`)대로 차례로 볼 수 있게, 페이지 끝에 다음 페이지 버튼을 더했습니다. PRD 1차 추가 요청으로 넣었습니다.
- 버튼은 맨 위로와 같은 모양이고, 맨 위로 바로 왼쪽에 둡니다. 끝까지 내려 맨 위로가 푸터 위에 멈출 때만 보입니다(`src/components/back-to-top.tsx`).
- 글은 다음 페이지의 한글 제목입니다. 마지막 페이지인 이력서 끝에는 처음(홈)으로 돌아가는 "처음으로" 버튼을 둡니다.
- 헤더 메뉴의 목록을 `src/lib/nav.ts`로 옮겨, 헤더와 다음 버튼이 같은 순서와 제목을 씁니다.
- 정한 값과 비교판 캡처는 [03-design.md](../03-design.md)의 "다음 페이지 버튼"과 [docs/design/next-page/](../design/next-page/)에 있습니다.
