# 2026-11-11 영상 제작 항목의 영상 목록

## 한 일

- `/ai`의 영상 제작 항목 안에 영상 목록을 두었습니다. 지금은 Recueve 소개 영상과 Jake English 소개 영상 두 편입니다. 데스크톱은 영상 칸을 두 칸씩 나란히, 모바일은 위아래로 쌓습니다.
- 데이터는 `content/site/ai/video.md`의 `videos` 목록입니다. 새 영상은 목록 한 덩이와 썸네일 그림 하나만 더하면 되고, 썸네일은 화면 코드가 경로로 찾습니다(`import.meta.glob`).
- 항목 머리(머리글, 문제)는 영상 여러 편을 아우르는 말로 바꿨습니다. Recueve 영상의 글은 고치지 않고 영상 칸으로 옮겼습니다. 홈 AI 카드는 그대로 Recueve 소개 영상을 보입니다.
- 내용 시험(영상마다 칸, 썸네일 파일, 순서, 홈 카드와 목록이 같은지)과 E2E(영상 칸의 이름, 그림 설명, 링크, 두 칸 배치)를 더했습니다.
- IA, PRD, 디자인 문서, [AI 사례 가이드](../guide/CONTENT_AI_사례_20261020.md)에 기준을 남기고, 캡처 네 장을 [docs/design/ai-video/](../design/ai-video/)에 두었습니다.

## 바로잡은 것

- **빌드에서만 비는 썸네일**: 개발 서버에서는 두 썸네일이 보였는데 `npm run build`가 `/ai`를 미리 그리다 멈췄습니다. `import.meta.glob`에 `{ import: "default" }`를 주면 빌드에서는 값이 모두 `undefined`였습니다. 모듈째 불러 `default`를 꺼내도록 고쳤고, 찾지 못하면 오류를 내게 해 빈 그림으로 조용히 지나가지 않게 했습니다. 빌드 도구가 처리하는 기능은 개발 서버만 보지 말고 빌드 결과까지 확인하라는 것을 가이드에 남겼습니다.
