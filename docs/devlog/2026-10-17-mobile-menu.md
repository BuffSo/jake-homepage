# 2026-10-17 모바일 메뉴와 푸터

## 한 일

- 모바일 메뉴 버튼을 "메뉴" 글자에서 아이콘(☰, 열리면 X)으로 바꿨습니다. 이름 "메뉴"는 화면 읽기용으로 남겼습니다.
- 펼친 메뉴를 폭 10rem 상자에서 헤더 아래 화면 폭 전체 패널로 바꾸고, 줄마다 이름과 페이지 제목(포트폴리오, AI로 일하는 방식, 이력서)을 두었습니다. 뒤 페이지는 어둡게 덮습니다.
- 푸터에서 "이 사이트의 소스"를 빼고 "© 2026 소재희"만 남겼습니다.
- 첫 화면 연락 줄의 GitHub를 이름 대신 주소(`github.com/BuffSo`)로 보이게 했습니다.
- 정한 모양과 동작, 구현하며 겪은 문제를 [모바일 메뉴](../guide/UI_모바일_메뉴_20261017.md) 가이드로 남겼습니다. 시안과 구현 캡처는 [design/mobile-menu](../design/mobile-menu/)에 있습니다.

| 5 | (제 제안) 첫 화면 연락 줄의 GitHub도 이메일처럼 주소로 보이게 한다 | 375에서 한 줄에 드는지 재 보고 같은 PR에 넣음 | 반영. 줄 길이 257px에서 328px, 폭 343px 안 |

## 바로잡은 것

- **범위를 넓힌 것**: 메뉴에 연락처를 넣지 말자는 판단을 받고, 묻지 않은 푸터까지 바꾸자며 시안을 만들었습니다. 그 과정에서 푸터에 연락처가 있다고 잘못 말하기도 했습니다(푸터에는 연락처가 없었습니다). 메뉴 일은 메뉴에서 끝내고, 다른 곳을 바꿀 일이 보이면 시안을 만들기 전에 한 줄로 묻습니다.
- **다크의 덮는 층**: 라이트와 같은 검정 20%로 덮었더니 다크 바탕에서는 보이지 않았습니다. 다크 캡처를 찍어 보고 색 토큰 `--scrim`을 만들어 다크만 60%로 올렸습니다.
- **페이지 제목 확인 기준**: 메뉴의 페이지 제목을 각 페이지 h1과 비교하는 E2E를 썼는데, 이력서의 h1은 원문의 이름("소재희")이라 실패했습니다. 브라우저 제목 앞부분과 비교하도록 바꿨습니다.

## 검증

- `npm run verify`: 11개 모두 통과(E2E 185개 통과, 19개 건너뜀).
- 새 E2E: 아이콘 버튼의 이름과 X 바뀜, 패널이 헤더 아래 화면 폭 전체인지, 줄의 페이지 제목과 브라우저 제목, 헤더 빈 곳과 덮은 곳을 누르면 닫힘, 푸터에 링크 없이 저작권 한 줄, 첫 화면 GitHub 주소.
- 개발 서버 375에서 라이트와 다크로 열고 닫기, 키보드(Tab, Enter로 열기, Esc로 닫고 버튼에 초점)를 확인했습니다. 1280의 데스크톱 헤더는 그대로입니다.
