# 2026-10-19 대표 주소 jakeso.dev

## 한 일

- 사이트만 쓰는 도메인 `jakeso.dev`를 Vercel에서 등록하고 `jake-homepage` 프로젝트에 붙였습니다. `www.jakeso.dev`는 `jakeso.dev`로 308합니다.
- 결정은 [ADR-0011](../adr/0011-jakeso-dev-domain.md)에 남겼습니다. ADR-0005의 도메인 줄에는 0011로 바뀌었다고 적었습니다.
- 코드의 기준 주소(`SITE_URL`), 공유 미리보기 그림, E2E의 주소를 바꿨습니다. canonical, og:url, 사이트맵, robots, JSON-LD가 이 값을 따라갑니다.
- 옮기는 순서와 겪은 문제를 [검색과 공유 정책](../guide/SEO_검색과_공유_정책_20261017.md) 가이드의 "대표 주소를 옮길 때"에 남겼습니다.

## 바로잡은 것

- **`www`를 더하다 루트가 넘어간 것**: Vercel의 도메인 추가 대화상자에서 Enter를 눌러, 연결 방식을 고르기 전에 `www.jakeso.dev`가 Production으로 붙었습니다. 그 바람에 `jakeso.dev`가 `www`로 308되게 바뀌었습니다. 루트를 Production으로 되돌린 뒤 `www`를 루트로 308시켰습니다. 막는 방법은 가이드에 적었습니다.

## 검증

- `curl -sI`: `https://jakeso.dev/work` 200, `https://www.jakeso.dev/work` 308 → `https://jakeso.dev/work`.
- 새 미리보기 그림을 열어 주소 글자를 확인했습니다.
- `npm run verify` 결과는 PR에 붙입니다.
