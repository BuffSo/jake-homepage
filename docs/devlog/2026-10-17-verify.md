# 2026-10-17 npm run verify (F6)

## 한 일

- `npm run verify` 하나로 검사 열한 개를 순서대로 돌립니다.
  - 순서: 민감정보, 길이 단위, 스크립트 테스트, 린트, 타입, 동기화 확인, 기술 층, 빌드, 움직임 코드 용량, E2E, 화면 캡처 확인.
  - 실패해도 끝까지 돌리고 마지막에 표(검사, 결과, 시간)로 요약합니다. 실패가 하나라도 있으면 1로 끝납니다.
  - 앞 검사가 통과하지 않으면 그 검사에 기대는 검사(움직임 용량, E2E, 캡처 확인)는 건너뜁니다. 건너뛴 이유가 실패인지, 건너뜀인지, 돌지 않았는지 표에 적습니다.
  - 로컬 전용 검사(동기화 확인, 기술 층)는 `.env.local`에 경로가 없으면 건너뜁니다.
- 주요 화면 캡처 18장(4페이지 × 라이트·다크 × 두 폭, 이력서 인쇄 두 폭)을 `test-results/captures/`에 모읍니다.
  - `npm run check:captures`가 모두 생겼는지 봅니다. 픽셀 비교는 하지 않습니다.
  - CI는 통과해도 캡처를 artifact로 올립니다.
- CI는 검사를 단계별로 두고, verify의 검사 목록과 CI 단계가 같은지 테스트로 확인합니다. 예외는 로컬 전용 둘과 CI 전용 gitleaks입니다.
- "이 사이트" 카드의 CI 검사 수는 캡처 확인이 더해져 10가지가 됩니다. 캡처 올리기 단계는 검사가 아니라서 세지 않습니다.
- `CLAUDE.md`의 작업 순서 5가 `npm run verify`를 가리킵니다.
