## 바로잡은 것

- **홈 카드의 링크 수**: `/ai`에서 "이 사이트"에 ADR 목록과 작업 일지 링크를, Jake Hermes에 저장소 링크를 더하면 홈 카드에도 그대로 버튼이 늘어납니다. 링크에 `home: true`를 단 것만 홈 카드에 보이게 해 홈 화면은 기획대로 두었습니다.
- **홈 카드 순서**: `order`를 `/ai`의 순서로 바꾸면서 홈 카드 순서가 섞이지 않게 `home`(홈 순서)을 따로 두었습니다. 홈 E2E도 홈에 싣는 넷만 기대합니다.
- **커밋 훅 오탐**: 같은 명령에 `grep -n`과 `git commit`이 함께 있으면 Claude Code 훅이 `--no-verify`로 잘못 읽고 막습니다(todo 03). 명령을 나눠 진행했습니다.
