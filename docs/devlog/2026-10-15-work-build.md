## 바로잡은 것

- **모바일 가로 스크롤**: 챕터 머리의 grid에 열을 정하지 않아, 모바일에서 열이 Recueve 캡처의 원래 폭(575px)만큼 늘어났습니다(문서 폭 605px). 헤드리스 캡처로 잡았고, 열을 `minmax(0, 1fr)`로 고정했습니다. `/work` E2E에 가로 스크롤 검사를 넣었고, [03-design.md](../03-design.md#f2에서-정한-값)에 적었습니다.
- **E2E 타입 오류**: 오류 수집 함수를 `e2e/helpers.ts`로 옮기면서, 다른 함수가 쓰던 `Page` 타입 import까지 지웠습니다. `npm run test:e2e`의 빌드 단계에서 TypeScript가 잡았습니다. e2e 파일을 고친 뒤에도 `npm run typecheck`를 먼저 돌립니다.
- **개발 서버의 오래된 모듈**: `content.ts`에 함수를 더한 뒤 개발 서버가 이전 모듈을 붙잡아 `/work`가 500이었습니다. 서버를 다시 띄워 해결했고, 빌드와 E2E에서는 생기지 않았습니다.
