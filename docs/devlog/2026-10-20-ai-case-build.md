# 2026-10-20 AI 도구 활용 사례 페이지 구현

## 한 일

- 동기화가 글(md, txt, json)과 그림(png)을 함께 다루게 했습니다. 그림은 바이트 그대로 옮기고 `--check`도 바이트로 비교합니다. 같은 날 원본 저장소가 이력서 md를 `이력서/`로 옮겨 허용 목록의 경로도 고쳤습니다.
- `/ai/case`를 만들었습니다. 4컷 2×2, 본문, `/work` 원문과 `/ai`로 가는 링크가 있고, `/ai` 맨 위에 입구 띠를 두었습니다. `/ai/case`에서도 헤더의 AI에 밑줄을 붙이고 `aria-current="true"`로 알립니다.
- 사례 페이지 E2E와 캡처를 더해 주요 화면 캡처가 18장에서 22장이 되었습니다.
- 기준과 겪은 문제를 [CONTENT_AI_사례 가이드](../guide/CONTENT_AI_사례_20261020.md)에 남겼습니다.

## 바로잡은 것

- **작은 단계마다 멈춘 것**: 커밋과 푸시 하나마다 다음 일을 묻고 멈춰, 사용자가 정한 일은 질문이 생길 때까지 이어서 하라고 했습니다. 구현 계획 승인처럼 정한 확인 지점에서만 묻고 이어서 진행했습니다.
- **가이드 문서 수**: 기획 때 ProWith 가이드를 72개로 세었지만 색인 파일까지 센 값이었습니다. 기획 devlog의 줄을 고치고, 세는 기준을 먼저 맞추는 일을 가이드에 남겼습니다.
- **원본의 다른 변경도 함께 들어옴**: 다시 동기화하자 DNS 문장 말고도 포트폴리오의 굵은 글씨 하나가 `<strong>` 태그로 바뀌어 들어왔습니다(원본 PDF의 굵은 글씨 수정). `/work`에서 굵은 글씨와 코드 표시가 그대로인 것을 확인하고 동기화 커밋 메시지에 적었습니다.
