## 리뷰 비교 (pr-review와 Gemini 4 Argon)

같은 PR(커밋 `a000146`)을 두 방식으로 리뷰했습니다.

| | pr-review (Claude, 6명 + 점수) | Gemini 4 Argon High (`agy`, 1회) |
|---|---|---|
| 걸린 시간 | 약 5분 | 약 17분 |
| 게시 기준을 넘은 지적 | 0건 (경계선 2건, 스펙 참고 1건) | 5건 (중간 1, 낮음 4) |
| 겹친 지적 | 테스트 머리 주석이 옛 규칙 그대로 | 같은 지적을 예외 규칙 문구와 묶어 더 넓게 봄 |
| 한쪽만 잡은 것 | devlog 누락, 표지 주석 누락 | 예외 문구가 기술 이름을 포함하지 않음, 글자 수 기준의 자리 잡기, drop 규칙이 인용 줄에도 걸림, 표지 오판정(주석 줄, 빈 설정), PR 본문 비교 표 누락 |

- Argon의 다섯 건은 모두 검증해 보니 실제로 해당했고, 같은 PR에서 고쳤습니다. 다만 대부분 지금 데이터에서는 드러나지 않는 경계 조건입니다.
- pr-review의 버그 스캔도 글자 수 기준의 자리 잡기를 의심했지만, 지금 폭에서는 깨지지 않는다고 보고 지적하지 않았습니다. Argon은 같은 상황을 데이터가 바뀔 때의 위험으로 보고 지적했습니다.
- Argon은 로컬 전용 파일이 없는 새 클론에서 읽기 전용으로 돌렸고, 결과의 링크가 로컬 임시 경로를 가리켜 GitHub 주소로 바꿔 게시했습니다.
- 한 번의 비교라 리뷰 루프에 계속 넣을지는 아직 정하지 않았습니다. 다음 PR에서도 같이 돌려 보고 정합니다([todo 04](../todo/20261015_04_todo_gemini_argon_pr_review.md)).
