# 2026-11-11 Jake English 기술 스택과 읽히는 슬라이드

## 한 일

- `/ai/jake-english`의 본문 다섯 장 뒤, 끝 링크 앞에 "기술 스택" 절을 더했습니다. 묶음 다섯(폰 앱, Mac 서버, 음성 (Mac에서 실행), AI, 연결)과 기술 이름을 로고 없이 글자로 씁니다(`content/site/jake-english.md`의 `stack`). 기술 이름은 jake-english 저장소의 코드로 다시 확인했습니다([ADR-0010](../adr/0010-stack-from-source.md)의 원칙).
- 본문 1~4장의 슬라이드를 다시 찍었습니다. 1920×1080 슬라이드를 1560×690으로 잘라 쓰던 것을, 찍을 때만 칸과 글자 크기를 바꾼 데스크톱 판(1440 폭)과 모바일 판(960 폭)으로 나누고 `<picture>`로 40rem 아래에서 모바일 판을 씁니다. 원본 슬라이드 파일은 고치지 않았습니다.
- 슬라이드 본문 글자는 1280 화면에서 약 13px이던 것이 약 18px, 375 화면에서 약 6px이던 것이 약 13px이 되었습니다. 가장 작은 이름표도 1280에서 15px, 375에서 12px 이상입니다.
- 1장의 앱 첫 화면 폰은 보이는 크기와 그 안의 글씨를 전과 같게 두고, 옆 세 상자의 글만 키웠습니다.
- 정한 값은 [03-design.md](../03-design.md)의 "Jake English에서 정한 값", 찍는 방법과 겪은 문제는 [AI 사례 가이드](../guide/CONTENT_AI_사례_20261020.md)에 있습니다.

## 바로잡은 것

- 2번 흐름: 지시의 "제외"를 그림에서 빼라는 뜻으로 읽었습니다. 바꾸는 대상에서 빼라는 뜻이었습니다. 무언가를 지우는 쪽으로 읽었다면 보고할 때 먼저 밝히는 것을 가이드의 막는 방법에 적었습니다.
- 4장을 다시 짤 때 새로 붙인 class 이름이 슬라이드 원본 CSS의 상자 이름과 겹쳐 칸이 흰 상자로 덮였습니다. 이름을 바꿨고, 남의 페이지에 요소를 얹을 때 원본 CSS에서 이름을 먼저 찾는 것을 가이드에 적었습니다.
