## 바로잡은 것

- **이미지 MCP 표현**: 포트폴리오의 "직접 구현"은 README의 "Based on gemini-imagen-mcp-server (MIT)"와 맞지 않았습니다. 사실을 확인하는 단계에서 README를 열어 잡았습니다. 원본은 고치지 않고 원본 저장소의 `docs/todo/`에 남겼습니다.
- **개인 도구의 공개 범위**: F1에서 홈 카드에 위키의 쪽수와 Hermes가 지금 맡은 일을 실었습니다. 개인 도구는 만든 방법과 쓰는 법까지만 싣는다고 [02-ia.md](../02-ia.md#3-ai로-일하는-방식)에 적었습니다.

## 검증

- 시안은 정적 마크업으로 써서 헤드리스 Chromium으로 그렸습니다. 데스크톱과 모바일 모두 가로 스크롤이 없습니다.
- Hermes Agent 저장소(NousResearch/hermes-agent, MIT)가 있는 것을 GitHub API로 확인했습니다. 링크는 구현할 때 다시 열어 봅니다.
- ADR 수와 CI 검사 수는 빌드할 때 셉니다(지금 9개, 9가지).
