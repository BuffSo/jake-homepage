# 2026-11-23 홈 AI 섹션과 이력서에 대회 결과 띠 넣기

## 한 일

- 홈 "AI로 일하는 방식" 섹션의 소개 문장과 카드 네 장 사이에 띠 한 줄을 넣었습니다. 왼쪽에 "AX인재전쟁 온라인 상위 5%"와 "1회차 삼일PwC 과제 · 참가자 2,916명 중 · 2026.11", 오른쪽에 공개 인증서 페이지로 가는 "인증서 보기" 버튼이 있습니다.
- AX인재전쟁 온라인은 기업이 낸 실제 과제로 AI 실력을 겨루는 대회입니다. 띠에는 결과 한 줄과 인증서 링크만 실었습니다.
- 문구와 링크는 사이트 전용 글 `content/site/home.md`의 `sections.ai.award`에 두었습니다. 사실의 출처는 이력서의 대외활동 절과 공개 인증서 페이지입니다.
- 이력서를 다시 가져와 `/resume`에 자기소개 한 문단과 인증서 안내 한 줄, 대외활동 절이 생겼고, 강의·특강이 수상 앞으로 왔습니다. `content/site/resume-page.md`의 절 목록을 원문 순서에 맞췄습니다.
- `/resume` 대외활동 절의 항목을 홈과 같은 띠로 그렸습니다. 글은 원문 그대로이고, 한 줄의 ` | ` 앞뒤를 두 줄로 나눠 오른쪽에 "인증서 보기" 버튼을 붙였습니다(`rehypeBand`). 맨 위 목차는 열 칸 그대로입니다.
- 자리와 문구는 [IA](../02-ia.md#3-ai로-일하는-방식)에, 값과 캡처는 [디자인 문서](../03-design.md#홈-ai-섹션-띠에서-정한-값)에 있습니다.
- 생김새와 문구를 비교판에서 먼저 정했고 새 페이지, 새 컴포넌트, 의존성이 없는 변경이라 설계 문서와 계획 문서 없이 구현했습니다.

## 바로잡은 것

- 띠를 넣은 직후 개발 서버가 옛 CSS를 줘서 띠가 테두리 없는 목록으로 보였습니다. 서빙된 CSS에 새 클래스가 없는 것을 확인하고 `.next/dev`를 지워 다시 띄웠습니다. 화면을 보여 주기 전에 서빙된 CSS를 먼저 확인하는 순서를 지켰습니다.

## 검증

- E2E에 시험 하나를 먼저 더하고, 구현 전에 그 시험만 실패하는 것을 봤습니다(1280과 375). 두 줄 문구가 보이는지, 링크의 주소와 새 창, 띠가 섹션 머리와 첫 카드 사이에 있는지, 버튼이 오른쪽에 있는지를 봅니다.
- `/resume`도 E2E를 먼저 고쳐 실패를 봤습니다. 목차가 열 칸이고 대외활동이 없는지, 띠의 두 줄이 원문과 같은지, 버튼의 주소와 새 창, 인쇄에서 버튼이 빠지는지를 봅니다. 플러그인은 스크립트 테스트 세 개로 봅니다.
- 공개 인증서 주소는 로그인 없이 curl로 200과 페이지 제목을 확인했습니다.
- `npm run verify` 결과는 PR 본문의 표에 있습니다.
