## 배경

## 선택지

| 안 | 내용 | 따져 볼 것 |
|---|---|---|
| A | GitHub 아바타를 About 제목 옆에 작게 | 이미 공개된 이미지라 새로 공개하는 것이 없습니다. 원본 해상도와 사진인지 그림인지 확인이 필요합니다 |

| C | 지금처럼 넣지 않음 | 작업이 주인공이라는 구성은 그대로입니다 |

어느 안이든 첫 화면에는 넣지 않습니다. 첫 화면의 가장 큰 요소(LCP)가 첫 줄 글자인 것을 유지하기 위해서입니다.
