## 한 일

- 대표 주소는 `genys.kr`입니다. `www.genys.kr`과 `http://`로 들어오면 `https://genys.kr`로 영구 이동(308)합니다.
- Vercel 프로젝트에 두 도메인을 더하고, Vercel이 보여 준 값을 가비아 DNS에 넣었습니다([ADR-0005](../adr/0005-nextjs16-vercel-genys-domain.md)).
  - 더한 레코드는 루트 A 레코드와 `www` CNAME 두 개입니다.
  - 루트에는 메일(MX)과 인증(TXT) 레코드가 있어서 CNAME 대신 A 레코드를 씁니다.
  - 다른 하위 도메인과 메일 레코드는 건드리지 않았습니다.
- 인증서는 Vercel이 발급하고 갱신합니다(Let's Encrypt).
- `jake-homepage.vercel.app` 주소는 그대로 열립니다.
