# TODO: Gemini 4 Argon으로 PR 리뷰하기 (agy)

> 작성: 2026-10-15 · 고침: 2026-10-16
> 상태: **진행 중** (`pr-review`와 비교하는 중, 하나를 고를 예정)

## 결론
- PR 리뷰는 지금 두 방법을 같이 시험합니다. Claude로 리뷰하는 `pr-review` 스킬과 Gemini 4 Argon으로 리뷰하는 `argon-review` 스킬입니다. 몇 번 비교한 뒤 하나만 남깁니다.
- Argon은 Antigravity CLI(`agy`)로 돌립니다. 클라우드 설정(Vertex AI, GitHub Actions)은 하지 않습니다.

## argon-review 스킬
- 다른 저장소에서도 쓰려고 사용자 스킬(`~/.claude/skills/argon-review/`)로 만들었습니다. 이 저장소에는 들어 있지 않습니다.
- "아르곤 리뷰해줘"로 부릅니다. "PR 리뷰해줘"는 `pr-review`입니다.
- 흐름
  1. 저장소를 임시 폴더에 새로 클론하고 PR 머리 커밋을 받습니다. 프로젝트 폴더에서 돌리지 않는 이유는 셋입니다.
     - 로컬 전용 파일(`CLAUDE.local.md`, `.env.local` 등)이 클론에는 없어서, 그 내용이 공개 PR 코멘트에 섞일 수 없습니다.
     - 작업 중인 브랜치와 커밋하지 않은 변경을 건드리지 않고, PR의 마지막 커밋을 그대로 리뷰합니다.
     - 빌드 결과물(`node_modules`, `.next`)이 없어 읽을 것이 적습니다. 클론은 2초쯤 걸립니다.
  2. PR 본문, 한 번에 읽을 수 있게 나눈 diff, 바뀐 파일 목록, 규칙 파일 목록을 클론 안 `.review/`에 둡니다.
  3. `agy --mode plan --sandbox`로 읽기만 하게 돌립니다.
  4. 결과의 로컬 링크를 리뷰한 커밋의 GitHub 주소로 바꾸고, 배너 한 줄을 붙여 PR 코멘트로 답니다. 본문은 고치지 않습니다.
- 실행마다 걸린 시간, 라운드, 읽은 파일, 토큰, 한도 사용량을 스킬 폴더의 `runs.tsv`에 남깁니다.

- 남은 사용량은 `agy -p /usage`로 봅니다. 계정 전체의 값이고 정수 퍼센트라, 여러 세션에서 같은 때 돌리면 한 번에 쓴 양을 나눌 수 없습니다. 한 번의 양은 토큰 수로 비교합니다. Argon에는 주간 한도가 있고, 이번에는 첫 사용부터 정확히 1주 뒤로 초기화 시각이 잡혔습니다.
- 이 방법은 구독(AI Pro)이 끝나는 2026-12-29까지만 쓸 수 있습니다.
  - 그 뒤에도 쓰려면 Pro 이상을 다시 구독하거나 Vertex AI 종량제로 옮깁니다.
  - AI Plus에는 Argon이 없습니다.
- 이렇게 돌리면 터미널 명령이 거부됩니다. 모델이 명령을 쓰려 하면 답 없이 끝나므로, 리뷰 지시에서 명령을 쓰지 말라고 합니다. Flash 모델로 스킬을 시험하다 확인했습니다.
- Gemini CLI는 개인 구글 로그인을 거절합니다("Antigravity로 이전" 안내). 그래서 Gemini CLI가 아니라 `agy`를 씁니다.
- PR이 열릴 때마다 자동으로 리뷰하려면 GitHub Actions와 Vertex AI가 필요합니다. 지금은 하지 않습니다.
