## 배경

이력서(/resume)의 스킬 줄과 프로젝트 스택 줄을 단색 로고가 든 칩으로 바꿨습니다(2026-10-28). 칩 모양은 /work 스택 칩과 같지만, /work에는 아직 로고가 없습니다. 그래서 같은 프로젝트의 스택이 /work에서는 로고 없이, /resume에서는 로고와 함께 나옵니다.

## 정할 것

- /work 스택 칩(`StackChips`)에도 `TECH_LOGOS`의 로고를 넣을지 정합니다.
- 넣는다면 /work의 기술 이름 표기와 로고 키가 맞는지 확인합니다. 예를 들어 "Next.js 16"처럼 버전이 붙은 이름이 있습니다.
- 첫 화면 기술 층의 기술 이름에는 넣지 않는 쪽이 맞는지도 함께 봅니다. 층은 강조색 글자로 서비스와 짝을 보여 주는 곳입니다.
- 화면 모양을 바꾸는 결정이라, 개발 서버에서 지금 화면과 시안을 캡처해 비교판으로 보고 정합니다.

## 정한 것 (2026-10-29)

- /work 스택 칩에도 이력서 칩과 같은 로고를 같은 크기로 넣습니다.
- 버전이 붙은 이름은 끝의 숫자를 떼고 찾습니다. 두 칩 목록이 같은 `techLogo`를 씁니다. Tailwind CSS, Three.js, Resend, Vitest를 목록에 더했습니다.
- 첫 화면 기술 층에는 넣지 않습니다.
