## 요청

`/work`와 `/ai`는 페이지 머리 아래에 이 페이지의 목차(섹션 바로 가기)가 있습니다. 스크롤해 내려가면 목차가 보이지 않으니, 맨 위로 돌아가는 버튼이 있으면 좋겠다는 요청입니다(2026-10-17).

## 기획 때 정할 것

- 어느 페이지에 둘지: `/work`, `/ai`, 목차가 없는 `/resume`도 둘지
- 언제 보일지: 목차가 화면에서 사라진 뒤부터
- 모양과 자리: 오른쪽 아래 고정 버튼인지, 모바일에서 본문과 버튼을 가리지 않는지
- 어디로 갈지: 페이지 맨 위인지, 목차인지
- 움직임 줄이기 설정에서는 부드러운 스크롤을 끌지
- 이력서 인쇄 화면에서는 숨기기

## 참고

- 목차는 `src/components/work/work-index.tsx`와 `src/components/ai/ai-index.tsx`입니다. 둘 다 화면에 고정하지 않기로 했습니다([02-ia.md](../02-ia.md)).
- PRD에 없는 요청이라, 진행할 때 PRD에 더할지 먼저 묻습니다(CLAUDE.md 작업 순서 1). 동작이 바뀌는 일이라 feature 브랜치와 PR로 합칩니다.

## 정한 것

질문 라운드 없이 아래 추천안으로 진행했습니다(2026-10-17). 자세한 내용은 [02-ia.md 공통 요소](../02-ia.md#공통-요소)와 [03-design.md](../03-design.md#맨-위로-버튼에서-정한-값)에 있습니다.

- 어느 페이지: 네 페이지 모두. 처음에는 목차가 있는 세 페이지만 정했다가, 홈도 화면 5~7개 길이라 요청에 따라 더했습니다.
- 언제: 위쪽의 길잡이(세 페이지는 목차, 홈은 서비스 목록이 든 첫 화면)가 화면 위로 다 사라진 뒤부터. 다시 보이면 숨습니다.
- 모양과 자리: "↑ 맨 위로" 테두리 버튼, 본문 여백 선의 오른쪽 아래. `sticky`라 페이지 끝에서는 푸터 위에 멈춥니다.
- 어디로: 페이지 맨 위로 올라가고 길잡이(목차나 첫 화면)에 초점을 둡니다.
- 움직임 줄이기: 부드러운 스크롤을 끄고 바로 올라갑니다.
- 인쇄: 숨깁니다.
