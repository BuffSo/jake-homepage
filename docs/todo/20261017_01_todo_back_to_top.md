## 요청

`/work`와 `/ai`는 페이지 머리 아래에 이 페이지의 목차(섹션 바로 가기)가 있습니다. 스크롤해 내려가면 목차가 보이지 않으니, 맨 위로 돌아가는 버튼이 있으면 좋겠다는 요청입니다(2026-10-17).

## 기획 때 정할 것

- 어느 페이지에 둘지: `/work`, `/ai`, 목차가 없는 `/resume`도 둘지
- 언제 보일지: 목차가 화면에서 사라진 뒤부터
- 모양과 자리: 오른쪽 아래 고정 버튼인지, 모바일에서 본문과 버튼을 가리지 않는지
- 어디로 갈지: 페이지 맨 위인지, 목차인지
- 움직임 줄이기 설정에서는 부드러운 스크롤을 끌지
- 이력서 인쇄 화면에서는 숨기기

## 참고
