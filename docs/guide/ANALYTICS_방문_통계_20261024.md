# 방문 통계

> 정함: 2026-10-24 ([ADR-0012](../adr/0012-vercel-web-analytics.md), PR #42에서 넣고 본인 방문 빼기를 더함)
> 코드: `src/components/site-analytics.tsx`, `src/components/page-views.tsx`, `src/components/outbound-clicks.tsx`, `src/lib/outbound.mjs`, `src/lib/stats-opt-out.mjs`
> 확인: `scripts/lib/outbound.test.mjs`, `scripts/lib/stats-opt-out.test.mjs`

사이트의 방문 통계를 어떻게 세는지에 대한 기준입니다. 다른 사이트에 방문 통계를 넣을 때도 같은 방식으로 씁니다. 구현하며 겪은 문제와 확인 방법도 함께 둡니다.

## 정한 것

| 항목 | 정한 것 | 이유 |
|---|---|---|
| 도구 | Vercel Web Analytics | 배포하는 Vercel에서 켜기만 하면 되고, 쿠키 없이 셉니다 |
| 세는 것 | 페이지 조회, 사이트 밖으로 나가는 링크와 이메일 링크의 클릭 | 페이지 조회만으로는 어느 서비스를 열어 보는지 보이지 않습니다 |
| 클릭에 담는 값 | 목적지(호스트와 경로, 쿼리와 해시는 뗌), 누른 페이지의 경로. 이메일 링크는 주소 대신 `email` | 무엇을 눌렀는지만 알면 되고, 주소나 쿼리에 개인 정보가 섞일 수 있습니다 |
| 세지 않는 것 | 방문자 식별, 사람별 흐름, 스크롤과 머문 시간, 입력값 | 익명 집계까지만 씁니다 |
| 알림 | 사이트에 따로 알리지 않고 문서(PRD, ADR)에만 적음 | 쿠키와 개인 식별이 없습니다 |
| 넣는 곳 | Vercel 운영 배포(`VERCEL_ENV`가 `production`)에서만 | 로컬과 CI에서는 스크립트가 404를 내고, 미리보기 배포의 방문은 대부분 확인용이라 잡음과 요금만 늘어납니다 |
| 클릭을 잡는 곳 | 링크마다 코드를 달지 않고 문서 전체의 클릭을 한곳에서 | 마크다운 원문의 링크까지 빠짐없이 잡힙니다 |
| 본인 방문 | 본인 브라우저에 표시를 남겨 뺌(아래 절) | 방문이 적은 사이트라 본인이 확인하는 방문이 숫자를 크게 흔듭니다 |
| 요금 | Pro 팀에서 이벤트 1,000건마다 0.03달러(사용 크레딧에서 먼저 씀), 보관 12개월 | 커스텀 이벤트(클릭)는 Pro 이상에서만 셉니다. 이벤트 하나에 값은 2개까지, 이름과 값은 각각 255자까지입니다 |

## 만드는 방법

- **켜기**: Vercel 프로젝트의 Analytics 탭에서 Web Analytics를 켭니다. 켠 뒤에 배포해야 합니다. 2판 패키지는 빌드할 때 Vercel이 주는 설정으로 스크립트 주소를 정하기 때문입니다.
- **설치**: `npm i -E @vercel/analytics`로 정확한 판을 고정해 넣습니다.
- **컴포넌트**: 뿌리 레이아웃에 서버 컴포넌트 하나를 두고, 그 안에 클라이언트 컴포넌트 두 개를 둡니다.
  - `SiteAnalytics`(서버)는 `process.env.VERCEL_ENV !== "production"`이면 아무것도 그리지 않습니다. 빌드 때 그려지므로 빌드할 때의 값으로 정해집니다.
  - `PageViews`(클라이언트)는 `@vercel/analytics/next`의 `<Analytics beforeSend={...} />`를 그립니다.
  - `OutboundClicks`(클라이언트)는 바깥 링크 클릭을 잡습니다.
- **바깥 링크 클릭**
  - `document`에 `click`과 `auxclick`(가운데 버튼, `button === 1`만)을 겁니다. `event.target.closest("a[href]")`로 링크를 찾습니다.
  - 순수 함수 `outboundEvent(a.href, location.href)`가 `{ to, from }`이나 `null`을 돌려주고, 값이 있으면 `track("outbound", 값)`을 부릅니다.
  - 오른쪽 메뉴로 새 탭에 여는 것은 잡지 못합니다.

## 본인 방문 빼기

- **새 브라우저나 기기에서**: 사이트 주소에 `?stats=off`를 붙여 한 번 엽니다(예: `https://jakeso.dev/?stats=off`). 화면에는 아무것도 바뀌지 않습니다. 그 뒤로 그 브라우저에서는 몇 번을 열어도 페이지 조회와 링크 클릭을 보내지 않습니다.
- **다시 세려면**: `?stats=on`을 붙여 한 번 엽니다.
- **켜고 끄는 방문**: 그 방문 자체도 보내지 않습니다.
- **다시 해야 하는 경우**: 표시는 브라우저마다 따로 남습니다. 다른 브라우저, 시크릿 창, 사이트 데이터를 지운 브라우저에서는 다시 셉니다.
- **표시를 확인하려면**: 개발자 도구의 localStorage에서 `stats-off` 키를 봅니다. 대시보드의 숫자가 늘지 않는지로도 확인할 수 있습니다.
- **동작 원리**
  - `beforeSend`가 기록마다 localStorage의 표시와 기록의 주소(`event.url`)를 봅니다. 규칙은 `statsDecision(url, optedOut)` 순수 함수에 둡니다.
  - 주소에 `stats=off`가 있으면 표시를 남기고, `stats=on`이 있으면 지웁니다. 표시가 있으면 `null`을 돌려줘 보내지 않습니다.
  - 표시는 쿠키가 아니고 어디로도 보내지 않습니다. localStorage를 쓸 수 없는 브라우저는 그대로 셉니다.
- **다른 사이트에 옮길 때**: 쿼리 이름과 localStorage 키만 정하면 그대로 씁니다.

## 겪은 문제와 해결

### 로컬과 CI 빌드에서 통계 스크립트가 404 (2026-10-24, PR #42)

- **증상**: 패키지는 `NODE_ENV`가 production이면 `/_vercel/insights/script.js`를 부릅니다. 그런데 로컬 `next start`에는 이 경로가 없어 404가 납니다. E2E는 400 이상 응답을 오류로 세므로 통계를 넣으면 깨집니다.
- **고친 것**: Vercel 운영 배포에서만 통계 컴포넌트를 그립니다(위 `SiteAnalytics`).
- **확인 방법**: 운영 동작은 `VERCEL_ENV=production npm run build`로 빌드해 띄워서 봅니다.

### 자동화 브라우저의 방문은 집계되지 않음 (2026-10-24)

- **증상**: 배포 뒤 헤드리스 Playwright로 홈을 열고 링크를 눌렀는데, 대시보드에 아무것도 잡히지 않았습니다.
- **원인**: Vercel 통계 스크립트는 `navigator.webdriver`가 참이거나 UA에 `Headless`가 있으면 아무것도 보내지 않습니다. 운영에서 받은 스크립트를 읽어 확인했습니다.
- **확인 방법**
  - 운영 확인은 일반 브라우저로 합니다.
  - 로컬 자동 시험에서는 `navigator.webdriver`를 false로, UA를 일반 브라우저 값으로 바꿉니다.
  - 통계 스크립트 요청에는 운영에서 받은 스크립트를 돌려주고, 수집 요청(`/_vercel/insights/view`, `/event`)은 가로채 200으로 답하며 셉니다.

### 서버 컴포넌트에서 `beforeSend`를 넘길 수 없음 (2026-10-24)

- **증상**: 운영 배포인지 가리는 서버 컴포넌트에서 `<Analytics beforeSend={fn} />`를 그리면, 함수는 서버에서 클라이언트로 넘길 수 없습니다.
- **고친 것**: `<Analytics />`를 클라이언트 컴포넌트(`PageViews`)로 옮겼습니다. `beforeSend`는 모듈 수준에 둡니다. 함수 참조가 바뀌면 `Analytics`가 훅을 다시 등록하기 때문입니다.

### `beforeSend`가 링크 클릭에도 적용되는지 (2026-10-24)

- 문서는 페이지 조회를 예로만 설명합니다.
- 운영 스크립트를 읽어 보니 페이지 조회와 `track` 이벤트가 같은 전송 함수를 지나고, 그 안에서 `beforeSend`를 부릅니다. 그래서 한 번 거르면 둘 다 빠집니다.
- 위의 로컬 자동 시험으로도 확인했습니다. `?stats=off` 뒤에는 사이트 안 이동의 조회와 바깥 링크 클릭이 하나도 가지 않았습니다.
