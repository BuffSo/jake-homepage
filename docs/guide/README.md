# 가이드

개발하면서 같이 정한 규칙과 정책을 정한 이유와 함께 남깁니다. 그 분야를 구현하며 겪은 문제와 해결(증상, 원인, 고친 것, 같은 실수를 막는 방법)도 함께 둡니다. 다음에 같은 종류의 일을 할 때, 다른 프로젝트에서 비슷한 것을 만들 때 따르는 기준입니다.

- 이 사이트의 페이지 구조와 디자인, 움직임은 `docs/02-ia.md`, `docs/03-design.md`, `docs/04-motion.md`에, 되돌리기 어려운 결정은 `docs/adr/`에 씁니다. 여기에는 다른 사이트를 만들 때도 따를 기준(정책, 다시 쓰는 화면 패턴)을 둡니다. 내용이 그 문서들과 겹쳐도, 가이드만 읽고 따라 할 수 있게 씁니다.
- 파일 이름은 `<분야>_<주제>_YYYYMMDD.md`입니다. 분야는 대문자 영어로 씁니다.
