# 02. 정보 구조 (IA)

- 상태: 초안 (2026-10-14)

## 페이지

| 경로 | 내용 | 단계 |
|---|---|---|
| `/` | 홈. 아래 섹션 순서 참고 | 1차 |
| `/work/recoeve` · `/work/prowith` · `/work/lotto-ai` | 프로젝트 상세 | 1차 |
| `/ai` · `/ai/[slug]` | AI 작업 카드 목록과 상세 | 1차 |
| `/resume` | 이력서 (인쇄용) | 1차 |
| `/en/...` | 영어 페이지 | 2차 |

### 홈 섹션 순서

1. **첫 화면** - 이름, 한 줄 소개, 서비스 세 개 카드, AI 활용 요약, 이메일과 GitHub
2. **운영 중인 서비스** - 카드에서 상세(`/work/[slug]`)와 라이브 서비스로 연결
3. **AI로 일하는 방식** - 대표 카드 세 개와 `/ai` 목록 링크
4. **경력** - 이력서와 같은 표기의 짧은 연표, `/resume` 링크
5. **연락** - 이메일, GitHub, 이 저장소

첫 화면에서 무엇을 만들었고 어떻게 일하는지가 다 보여야 합니다. 연출은 그 아래에 둡니다([03-design.md](03-design.md)).

### 공통 요소

- **헤더** - 이름, Work, AI, Resume
- **푸터** - 이메일, GitHub, "이 사이트의 소스"(이 저장소)
- **질문 창** (2차) - 모든 페이지에서 열 수 있는 패널

## 콘텐츠 흐름

```
비공개 커리어 저장소 (원본 md)
  │  npm run sync  (허용 목록, 전화번호 제거)
  ▼
content/synced/    ← 동기화 결과. 직접 고치지 않는다. 커밋한다.
content/site/      ← 이 사이트에서만 쓰는 글 (한 줄 소개, AI 작업 카드 등)
  │  빌드할 때 파싱
  ▼
페이지
```

`content/synced/`가 커밋돼 있으므로 원본 저장소가 없어도 누구나 빌드할 수 있습니다. 자세한 이유는 [ADR-0003](adr/0003-content-source-and-sync.md)에 있습니다.

## 콘텐츠 모델 (초안)

```ts
type Project = {
  slug: "recoeve" | "prowith" | "lotto-ai";
  title: string;
  summary: string;        // 한 줄 설명
  period: string;         // 예: "2026.04 ~ 2026.05"
  role: string;           // 예: "풀스택 (회사)"
  stack: string[];
  liveUrl: string;
  howToView?: string;     // "보시는 방법" 안내
  body: string;           // 상세 본문 (md)
};

type AiCard = {
  slug: string;
  title: string;
  problem: string;        // 무엇이 문제였나
  built: string;          // 무엇을 만들었나
  result: string;         // 무엇이 달라졌나 (확인 가능한 근거)
  links: { label: string; href: string }[];
};

type CareerItem = {
  org: string;
  role: string;
  period: string;
  summary: string;
};
```

필드는 1차 구현 때 확정하고 이 문서를 고칩니다.
