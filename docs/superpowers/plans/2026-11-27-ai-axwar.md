# AX인재전쟁 대회 결과 페이지 `/ai/axwar` 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 대회 결과를 설명하는 `/ai/axwar`를 만들고, 홈과 `/resume`의 대회 결과 띠 버튼을 이 페이지로 보냅니다. 공유 그림은 공통 그림 그대로입니다(Task 3은 구현 뒤 되돌림).

**Architecture:** 글은 새 사이트 전용 글 `content/site/axwar.md`의 머리말에 두고 `getAxwar()`로 읽습니다(형제 페이지 `/ai/jake-english`와 같은 방식). 띠는 `home.md`의 `sections.ai.award` 값만 바꾸면 `ButtonLink`가 사이트 안 링크로 그립니다. 공유 그림은 다른 페이지와 같은 공통 그림입니다(전용 그림을 만들던 Task 3은 되돌림).

**Tech Stack:** Next.js 16 App Router, TypeScript, Tailwind CSS 4, Playwright, node --test

**Spec:** `docs/superpowers/specs/2026-11-27-ai-axwar-design.md`

## Global Constraints
