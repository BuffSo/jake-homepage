# AX인재전쟁 대회 결과 페이지 `/ai/axwar` 설계

> 작성: 2026-11-27 (superpowers brainstorming)
> 상태: 사용자가 비교판의 네 질문에서 모두 추천안을 골랐습니다(배치 B, 버튼 A, 기간 빼기, 전용 공유 그림). 같은 날 공유 그림은 공통 그림으로 바꿨습니다(아래 "공유 정보").
> 표시: 「(AI 판단)」은 사용자가 정하지 않고 에이전트가 정한 것입니다. 표시가 없는 결정은 사용자가 정한 것입니다.

## 왜 하나

홈 "AI로 일하는 방식" 섹션의 대회 결과 띠는 버튼 "인증서 보기"가 대회 측 인증서 페이지로 바로 갑니다. 그래서 무엇을 어떻게 만들었는지 설명할 곳이 사이트에 없습니다. 같은 내용을 링크드인 글로 올렸지만 링크드인은 로그인해야 보이고, 카카오톡 인앱 브라우저에서는 로그인이 번거로워 공유하기 어렵습니다. 로그인 없이 열리고 공유하기 좋은 중간 페이지를 둡니다.

## 목표

- `/ai/axwar` 한 페이지에서 결과(상위 5%), 덧붙임 한 줄, 공개 인증서 카드, 만든 이야기(링크드인 글 네 문단)를 봅니다.
- 홈과 `/resume`의 대회 결과 띠 버튼이 이 페이지로 옵니다. 인증서 링크는 이 페이지 위쪽으로 옮깁니다.
- 링크를 카카오톡 등에 보내면 이 페이지만의 제목과 설명이 뜹니다. 그림은 모든 페이지가 같이 쓰는 공통 그림입니다. 사이트맵에 넣습니다.

## 하지 않을 것

- 헤더 메뉴에 넣지 않습니다. `/ai`에도 입구를 두지 않습니다. 띠를 홈에만 두고 `/ai`에는 싣지 않는다는 2026-11-23 결정을 그대로 둡니다. 페이지 주소만 `/ai` 아래입니다.
- `/resume` 본문의 "이틀 만에"(커리어 원본 문장)는 고치지 않습니다.
- 맨 위로 버튼과 다음 페이지 버튼은 두지 않습니다. `/ai/case`, `/ai/jake-english`와 같은 목차 없는 하위 페이지입니다. (AI 판단)

## 하면 안 되는 것 (싣지 않는 것)

- 제출한 앱 링크, 대회 때 만든 저장소, 대회가 나눠 준 문제지와 업무 흐름도
- 링크드인 글 네 문단과 위 사실 밖의 대회 이야기
- 주최 측 메일의 원문과 그 안의 링크
- 대회 때 만든 로컬 저장소의 경로

## 지금 코드에서 확인한 것

- **띠**: `src/components/award-band.tsx`의 `AwardBand` 하나를 홈(`src/components/home/ai-cards.tsx`)과 `/resume`(`src/app/resume/page.tsx`, `NEW` 뱃지)이 같이 씁니다. 문구와 링크는 `content/site/home.md`의 `sections.ai.award` 한 곳입니다. 버튼은 `ButtonLink`라 `http(s)` 주소면 새 창과 ↗, 사이트 안 주소면 같은 창의 `Link`가 됩니다. 그래서 `href`만 `/ai/axwar`로 바꾸면 ↗와 새 창이 저절로 빠집니다.
- **형제 페이지**: `src/app/ai/jake-english/page.tsx`, `src/app/ai/case/page.tsx`. 돌아가기 링크 "← AI로 일하는 방식", `SectionHead`(as h1), 굵은 선(`border-fg`) 아래 본문, 끝 버튼 줄 순서입니다. 글은 `content/site/*.md`의 머리말(YAML)을 `src/lib/content.ts`의 `read<T>()`로 읽습니다.
- **헤더**: `src/components/nav-links.tsx`가 `/ai/` 아래 경로에서 "AI"에 밑줄과 `aria-current="true"`를 붙입니다. 손댈 것이 없습니다.
- **공유 정보**: `src/lib/site-meta.ts`의 `pageMetadata({ title, description, path })`가 모든 페이지에 같은 그림(`src/assets/og-image.png`)을 넣습니다. 그림은 `scripts/og-image.mjs`(`npm run og:image`)가 개발 서버의 글꼴과 색으로 찍습니다. `e2e/seo.spec.ts`는 모든 페이지의 `og:image`가 `og-image.*.png`인지 봅니다.
- **사이트맵**: `src/app/sitemap.ts`의 `PATHS`, `e2e/seo.spec.ts`의 `PAGES`.
- **캡처**: `scripts/lib/captures.mjs`의 `PAGES`(지금 26장). `CLAUDE.md` 명령 목록과 `scripts/lib/captures.test.mjs`에 26이 적혀 있습니다.
- **방문 통계**: `src/components/outbound-clicks.tsx`가 문서 전체의 바깥 링크 클릭을 `outbound`로 셉니다. 인증서 링크는 이제 `/ai/axwar`에서 잡힙니다. 띠 버튼 클릭은 `/ai/axwar` 조회로 보입니다.

## 방법

비교판(개발 서버의 `/ai/jake-english` 화면에서 본문만 시안으로 바꿔 1280, 375로 찍음)에서 세 배치를 견줬습니다. 세 안 모두 글은 같고 제목의 모양과 인증서의 자리만 다릅니다.

| 안 | 모양 | 장점 | 단점 |
|---|---|---|---|
| A. 글 중심 | 형제 페이지와 같은 머리. 제목 "AX인재전쟁 대회 상위 5%", 인증서는 작은 회색 글 링크 | 형제 페이지와 가장 비슷합니다 | 인증서가 눈에 덜 띕니다 |
| **B. 숫자 강조 (고름)** | 제목이 큰 "상위 5%". 위에 대회 이름, 아래에 참가자 수, 덧붙임, 테두리 버튼 "인증서 보기" | 카카오톡에서 열면 첫 화면에 결과, 덧붙임, 인증서가 다 들어옵니다(디자인 원칙 1분 원칙, 증거가 먼저) | 제목 글자가 형제 페이지보다 커서 이 페이지만 다른 머리입니다 |
| C. 인증서 상자 | 머리는 A, 인증서를 홈 띠 모양 상자에 | 인증서가 가장 크게 보입니다 | "인증서"라는 말이 세 번 나옵니다 |

비교판에는 이 세 배치와 함께 띠 버튼 문구 세 안, 띠 둘째 줄 세 안(홈과 `/resume` 화면), 공유 그림 두 안(공통 그림과 전용 그림을 카카오톡 카드 모양에 넣은 것)이 있었습니다. 비교판 그림은 구현 때 `docs/design/ai-axwar/`로 옮깁니다(지금은 작업 폴더 밖 임시 폴더에 있음).

## 정한 것

### 페이지 짜임 (배치 B)

돌아가기 링크 → 머리 → 굵은 선 → 본문 네 문단 → 끝 버튼 → 푸터.

```
← AI로 일하는 방식
AI / AWARD
AX인재전쟁 온라인 1회차 · 삼일PwC 과제      (굵게)
상위 5%                                      (아주 크게)
참가자 2,916명 중 · 2026.11                  (회색)
┌ 인증서 그림 (전체 폭) ┐
│ AX인재전쟁 온라인 1회차 삼일PwC 상위 5% 인증서
└ axacademy.ai ↗        ┘                   (카드 하나, 새 창)

결과물 심사 상위 100명 보상(ChatGPT Plus 1개월) 수령   (카드 밖, 띄움)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
본문 네 문단
[AI로 일하는 방식]
```

- **돌아가기 링크**: "← AI로 일하는 방식"(`/ai`). 형제 페이지와 같습니다. (AI 판단)
- **머리글**: `AI / AWARD`. 형제 페이지의 `AI / CASE`, `AI / APP`에 맞춥니다. (AI 판단)
- **제목(h1)**: 화면에는 대회 이름 줄과 큰 "상위 5%" 두 줄로 보이고, 두 줄을 h1 하나에 넣습니다. 화면 읽기 프로그램과 검색엔진에는 "AX인재전쟁 온라인 1회차 · 삼일PwC 과제 상위 5%"로 읽힙니다. "상위 5%"만 h1이면 무엇의 결과인지 빠지기 때문입니다. (AI 판단)
- **참가자 줄**: "참가자 2,916명 중 · 2026.11", 회색.
- **덧붙임 줄**(확정 문구, 개조식): "결과물 심사 상위 100명 보상(ChatGPT Plus 1개월) 수령". 본문 글자색입니다. 인증서 카드 아래, 카드 테두리 밖에 띄워 둡니다(셋째 비교판, 2026-11-27). 처음에는 참가자 줄 아래, 카드 위였습니다. 카드 바로 밑이라 카드의 설명으로 읽히지 않게 사이를 넓히고 카드 안 글과 다른 글자로 씁니다.
- **인증서 카드**(2026-11-27 둘째 비교판에서 정함): 참가자 줄 아래에 링크드인 게시물의 링크 카드 같은 카드 하나. 그림 전체 폭(데스크톱 30rem까지) 아래에 제목 "AX인재전쟁 온라인 1회차 삼일PwC 상위 5% 인증서"와 도메인 "axacademy.ai". 카드 전체가 링크이고 새 창으로 https://axacademy.ai/axwar/cert/dxN6SEBhEGU6n1JU1brdfPa0 를 엽니다.
  - 그림은 인증서 페이지의 공유 그림(og:image, 1200×630)을 받아 `src/assets/ai/axwar/cert.png`에 둡니다. 인증서가 비공개로 바뀌어도 깨지지 않게 하려는 것입니다.
  - 제목은 인증서 페이지의 그림 설명(og:image:alt)입니다. 페이지 제목(og:title)은 이름에 "님"이 붙어 쓰지 않습니다.
  - 처음 설계는 덧붙임 아래 테두리 버튼 "인증서 보기 ↗"와 끝 버튼 줄의 채운 버튼 "인증서 보기 ↗"였습니다. 같은 버튼이 두 번 보인다는 사용자 지적으로 카드 하나로 바꿨습니다. 둘째 비교판에서 가로형(머리 아래), 세로형(머리 아래), 세로형(본문 끝)을 견줘 세로형 머리 아래를 골랐습니다.
- **본문**: 굵은 선 아래 링크드인 글 네 문단 그대로입니다. 폭은 형제 페이지 본문과 같은 45rem까지입니다.
  1. AX인재전쟁 온라인 1회차 삼일PwC 과제에서 참가자 2,916명 중 상위 5%에 들었습니다.
  2. 대회 기간은 7일이었지만 마감 전날 저녁에야 시작해, 하루 남짓 만에 만들고 마감 6분 전에 제출했습니다.
  3. 과제는 부서마다 다른 숫자로 판단해 결정이 늦어지는 가상 화장품 그룹에서, 대시보드나 보고서가 아니라 판단부터 승인과 처리까지 실제로 이어지는 AI 운영 시스템을 만드는 것이었습니다.
  4. Orca로 기능을 나눠 git worktree 여러 개에서 동시에 개발했습니다. 구현은 Claude Code로, 업무 흐름 검토는 Gemini로, 화면 테스트는 Codex와 Aside 브라우저로 했습니다.
- **끝 버튼**: "AI로 일하는 방식"(테두리 버튼, `/ai`) 하나입니다. 인증서는 카드 하나로만 갑니다.

### 글의 자리 (AI 판단)
