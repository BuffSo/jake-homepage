# ADR-0007: 사이트 전용 글의 앞부분 데이터는 yaml 패키지로 읽는다

- 상태: 채택
- 날짜: 2026-10-14

## 배경

홈의 카드와 첫 화면 문구는 `content/site/`의 md 파일에 둡니다([ADR-0003](0003-content-source-and-sync.md#원본에-없는-작업)). 파일 맨 위의 앞부분 데이터(frontmatter)에는 제목 문장, 숫자, 스택 목록처럼 목록과 중첩 값이 들어갑니다. Node에는 YAML 파서가 없어서 의존성이 하나 필요합니다.

## 검토한 안

| 안 | 장점 | 단점 |
|---|---|---|
| `yaml` 2.9 | 의존성 0개, 꾸준히 관리됨, YAML 1.2 규칙이라 날짜를 문자열 그대로 둠 | 패키지 크기가 큼(CJS와 ESM을 함께 담음). 빌드 때만 쓰므로 방문자에게는 영향 없음 |
| `gray-matter` 4.0 | frontmatter 분리까지 해 줌 | 2021년 이후 릴리스가 없고 의존성이 9개. 날짜를 `Date`로 바꿈 |
| 직접 만든 파서 | 의존성 없음 | 목록과 중첩 값을 제대로 다루려면 결국 파서를 하나 만들게 되고, 틀리기 쉬움 |
| md 대신 TypeScript 데이터 파일 | 의존성 없음, 타입 검사 | ADR-0003의 "md 사이트 전용 글" 방식과 어긋나고, 이미 쓴 `recueve.md`도 옮겨야 함 |

## 결정

- `yaml` 2.9 이상을 쓴다. 2.8.3에서 고쳐진 보안 공지(CVE-2026-33532)가 있으니 그보다 낮은 버전은 쓰지 않는다.
- frontmatter는 파일 맨 앞의 `---` 사이 블록을 정규식으로 떼어 `yaml`로 읽는다.
- 서버 컴포넌트에서 빌드 때만 읽는다(`src/lib/content.ts`, `server-only`). 방문자에게 내려가는 코드에는 들어가지 않는다.

## 영향

- `content/site/`의 md 파일은 frontmatter에 카드 데이터를, 본문에 긴 글을 둔다.
- 사실 검사 테스트(`scripts/lib/content.test.mjs`)도 같은 방식으로 파일을 읽는다.
