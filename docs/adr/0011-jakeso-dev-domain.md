# ADR-0011: 대표 주소를 jakeso.dev로 정한다

- 상태: 채택
- 날짜: 2026-10-19

## 배경

ADR-0005에서 정한 주소는 임시로 연결한 도메인이었습니다. 주소만 봐서는 누구의 사이트인지 알 수 없어, 이 사이트만 쓰는 도메인을 새로 정했습니다.

## 검토한 안

후보마다 등록 여부를 RDAP와 whois로 조회했습니다(2026-10-19).

| 안 | 장점 | 단점 |
|---|---|---|
| 지금 주소 유지 (ADR-0005) | 바꿀 일이 없습니다 | 임시로 연결한 도메인이고, 주소만으로 누구의 사이트인지 알 수 없습니다 |
| `sojaehee.dev`, `jaeheeso.dev` | 한글 이름과 바로 이어집니다 | 로마자 표기가 갈려 받아 적기 어렵습니다 |
| `buffso.dev` | GitHub 아이디와 같습니다 | buff가 무슨 뜻인지 설명이 필요합니다 |
| `jakeso.com` | 가장 익숙한 끝자리입니다 | 무엇을 하는 사람인지는 보이지 않습니다 |
| `jakeso.dev` | 저장소와 AI 도구 이름에 쓰는 Jake와 성(So)을 합쳤습니다. `.dev`로 개발자 사이트라는 것이 보입니다 | 한글 이름과는 바로 이어지지 않습니다 |

## 판단

AI는 후보를 조회해 `jakeso.dev`를 추천했습니다. 저는 `.com`과 무엇이 다른지 물었고, 주소는 대부분 링크로 전해져 직접 칠 일이 드물다는 근거를 보고 `.dev`로 정했습니다.

`.dev`는 최상위 도메인 전체가 브라우저의 HSTS 사전 등록 목록에 들어 있어 HTTPS로만 열립니다. 이 사이트는 이미 HTTPS로만 운영하고 인증서는 Vercel이 발급하므로 달라지는 것이 없습니다.

## 결정

| 주소 | 하는 일 |
|---|---|
| `jakeso.dev` | 대표 주소입니다. Vercel에서 등록했고(2026-10-19), DNS도 Vercel이 관리합니다 |
| `www.jakeso.dev` | `jakeso.dev`로 영구 이동(308)합니다 |
| 이전 주소(ADR-0005)와 그 `www` | `jakeso.dev`로 영구 이동(308)합니다. 경로는 그대로 붙여 넘깁니다 |

## 영향

- 사이트 기준 주소(`src/lib/site-meta.ts`의 `SITE_URL`)와 공유 미리보기 그림 속 주소(`scripts/og-image.mjs`)를 바꿉니다. 그림은 `npm run og:image`로 다시 만듭니다.
- E2E(`e2e/seo.spec.ts`), README, CLAUDE.md, 검색과 공유 정책 가이드의 주소를 바꿉니다.
- 이력서 원문에 있는 주소는 원본 저장소에서 바꾸고 동기화로 가져옵니다(ADR-0003). 그 전까지 `/resume`의 링크는 이전 주소를 가리키지만 308로 새 주소에 닿습니다.
- 검색엔진 등록은 새 주소로 합니다.
- 옮기는 순서와 확인 방법은 [검색과 공유 정책 가이드](../guide/SEO_검색과_공유_정책_20261017.md)의 "대표 주소를 옮길 때"에 있습니다.
