# ADR-0002: 방문자를 가리지 않는 개인 허브로 만든다

- 상태: 채택 (방문 통계 범위는 2026-10-24 ADR-0012로 넓힘)
- 날짜: 2026-10-14

## 배경

처음 기획에는 특정 방문자를 상정한 기능이 들어 있었습니다.

## 검토한 안

AI는 다음을 제안했습니다.

- 방문자마다 다른 링크를 내고 열람 여부와 시각을 기록하는 기능
- 특정 방문자를 상대로 저를 소개하는 형식의 질문 창

## 판단

이 페이지는 웹에 공개됩니다. 특정 독자를 상정해 만들면 다른 독자에게는 어색합니다. 누가 보든 같은 내용으로, 제가 만든 것과 일하는 방식을 현대적인 기술로 보여 주는 개인 허브여야 합니다.

참고로 [careerhackeralex.com](https://www.careerhackeralex.com/)을 분석했습니다. 소개와 이력은 짧은 단락과 인쇄용 이력서 페이지로 두고, 본문은 만든 것과 생각이 차지하는 구성입니다.

## 결정

- 방문자별 링크와 열람 기록은 만들지 않습니다.
- 질문 창은 "제 작업에 대해 물어보세요" 형식으로, 누구에게나 같은 방식으로 답합니다. 답변 기준은 [ADR-0004](0004-ask-answer-policy.md)에 있습니다.
- 소개는 짧게 두고, 운영 중인 서비스와 AI로 일하는 방식이 본문을 차지합니다.
- 사실은 이력서와 포트폴리오에 있는 것만 씁니다([ADR-0003](0003-content-source-and-sync.md)).

## 영향

- 방문 통계는 방문자를 식별하지 않는 익명 집계까지만 씁니다. 처음에는 페이지 단위로 정했고, 2026-10-24 바깥 링크 클릭까지 넓혔습니다([ADR-0012](0012-vercel-web-analytics.md)).
