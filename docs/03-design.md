# 03. 디자인 원칙

- 상태: 초안 (2026-10-14). 색과 간격 토큰은 1차 구현 때 정하고 이 문서에 기록합니다.

## 원칙

1. **1분 원칙** - 첫 화면에서 무엇을 만들었고 어떻게 일하는지가 다 보입니다. 스크롤 연출은 그 아래에 둡니다.
2. **증거가 먼저** - 꾸밈보다 라이브 링크, 실제 화면, 저장소 링크를 앞에 둡니다.
3. **움직임은 의미가 있을 때만** - 정보의 순서나 관계를 보여 줄 때만 움직입니다. `prefers-reduced-motion`이면 정지 화면으로 보여 줍니다.
4. **라이트와 다크** - 시스템 설정을 따릅니다. 두 모드 모두에서 대비 기준을 지킵니다.
5. **모바일 우선** - 좌우 여백 16px, 가로 스크롤 없음.
6. **인쇄** - `/resume`은 인쇄했을 때 A4 한 장 단위로 깔끔하게 나와야 합니다.
