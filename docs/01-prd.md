# 01. 요구사항 (PRD)

- 상태: 초안 (2026-10-14)
- 관련: [00-vision.md](00-vision.md) · [02-ia.md](02-ia.md) · [03-design.md](03-design.md) · [04-motion.md](04-motion.md) · [adr/](adr/)

## 목표

1. 제가 무엇을 만들었고 어떻게 일하는지 한곳에서 보여 줍니다.
2. 이 저장소로 AI를 활용한 개발 과정(기획, 결정, 구현, 검증)을 보여 줍니다.

## 성공 기준

| 기준 | 확인 방법 |
|---|---|
| 첫 화면만 보고도 한 줄 소개, 운영 중인 서비스 세 개, AI 활용 방식을 알 수 있다 | 화면 캡처 리뷰 |
| 사이트의 수치와 날짜가 이력서, 포트폴리오와 모두 같다 | 동기화 원본 대조 (F5) |
| 민감정보 노출 0건 | 커밋마다 `check:sensitive` 통과, CI 통과 |
| 모바일에서 가로 스크롤이 없다 | 375px 화면 캡처 |
| Lighthouse 성능과 접근성 90점 이상 | 배포 후 측정 |

## 범위

### 1차 (MVP)

| ID | 기능 | 수용 기준 |
|---|---|---|
| F1 | 홈 첫 화면 | 첫 줄과 짧은 움직임으로 시작해, 같은 화면 안에 한 줄 소개와 보조 문장, 기술 층 여섯 개, 서비스 세 개 증거 목록(이름, 한 줄 설명, 라이브 링크), 이메일과 GitHub가 남는다. 움직임은 [04-motion.md](04-motion.md)를 따르고, 움직임 줄이기 설정에서는 마지막 장면만 보인다 |
| F2 | 프로젝트 상세 `/work/[slug]` | Recoeve, ProWith, GENYS Lotto AI 세 페이지. 포트폴리오의 프로젝트 상세와 "보시는 방법" 안내를 담는다 |
| F3 | AI 작업 카드 `/ai` | 카드마다 문제, 만든 것, 결과를 쓴다. 첫 카드는 이 저장소다. 제품을 만든 사례만 싣는다 |
| F4 | 이력서 `/resume` | 이력서 md에서 생성한다. 전화번호를 뺀다. 인쇄용 스타일이 있다 |
| F5 | 콘텐츠 동기화 `npm run sync` | 허용 목록에 있는 원본 파일만 가져온다. 연락처 표에서 전화번호를 지운다. 결과를 `content/synced/`에 커밋한다([ADR-0003](adr/0003-content-source-and-sync.md)) |
| F6 | 검증 `npm run verify` | 타입체크, 린트, 테스트, 빌드, 민감정보 검사, 첫 화면 움직임 코드 용량(gzip 10KB 이하), 주요 화면 캡처를 한 번에 돌린다. 하나라도 실패하면 작업이 끝나지 않은 것이다 |

### 2차

| ID | 기능 | 수용 기준 |
|---|---|---|
| F7 | 질문 창 | [ADR-0004](adr/0004-ask-answer-policy.md) 기준을 따른다. 답마다 근거 섹션을 표시한다. 요청 수 제한과 하루 예산 상한이 있다. 평가 세트(`evals/qa/`)를 통과한다 |
| F8 | GENYS Lotto AI 라이브 카드 | 실제 서비스에서 최신 회차 데이터를 가져와 보여 준다. 일정 주기로 갱신한다. 서비스가 응답하지 않으면 마지막 값을 보여 준다 |
| F9 | GitHub 활동 카드 | 검증한 값만 보여 준다. 공개 API의 집계를 그대로 쓰지 않는다 |
| F10 | 영어 페이지 `/en` | 홈, 프로젝트 상세, 이력서 |
| F11 | OG 이미지 | 페이지마다 공유용 이미지를 자동 생성한다 |

### 3차 (검토)

- 첫 화면 아래 섹션의 스크롤 장면이나 3D 같은 인터랙션 강화. 1차를 공개한 뒤 반응을 보고 정합니다. 첫 화면 움직임은 1차 F1에 있습니다.
- "지금 하는 일" 섹션

## 하지 않을 것

| 항목 | 이유 |
|---|---|
| 블로그, CMS | 글이 몇 편에서 멈추면 오히려 비어 보입니다. 쓸 글이 쌓이면 다시 검토합니다 |
| 문의 폼 | 백엔드와 스팸 처리가 따라옵니다. 이메일 링크로 충분합니다 |
| 방문자별 추적 링크 | 누구에게나 같은 페이지를 보여 줍니다([ADR-0002](adr/0002-personal-hub-for-everyone.md)) |
| 전화번호 같은 개인 정보 | 공개 페이지입니다([ADR-0006](adr/0006-public-repo-and-privacy.md)) |
| Recoeve 소스 공개 | 회사에서 한 작업입니다 |

## 비기능 요구사항

- **성능** - 콘텐츠는 사전 렌더링한 정적 셸로 보내고, 동적인 부분만 따로 스트리밍합니다.
- **접근성** - 키보드로 모든 기능을 쓸 수 있고, 색 대비를 지키고, `prefers-reduced-motion`을 따릅니다.
- **비용** - 질문 창은 하루 예산을 넘으면 스스로 꺼집니다.
- **개인정보** - 질문 창의 질문을 저장할지와 보관 기간은 F7 착수 때 정합니다. 저장한다면 개인정보처리방침 페이지를 함께 만듭니다.
